# Drive Learning

אפליקציית לימוד קולית לנסיעות, שעובדת עם Android Auto.
הקורס הראשון: **Node.js ועבודה בבקאנד**.

## איך זה עובד

```
┌─────────────┐   סוף נסיעה: לוג התקדמות    ┌──────────────────┐
│  האפליקציה   │ ─────────────────────────▶ │  repo  (GitHub)   │
│  (טלפון+רכב) │ ◀───────────────────────── │  content/ progress│
└─────────────┘   לפני נסיעה: תוכן מעודכן   └──────────────────┘
       │                                         ▲        ▲
       │ מיד אחרי נסיעה                           │        │ בלילה
       ▼                                         │        │
┌─────────────┐   שאלות חדשות + בדיקת הסברים     │  ┌────────────┐
│ Gemini (API │ ─────────────────────────────────┘  │  Claude     │
│ חינמי)      │                                     │  (משימה     │
└─────────────┘                                     │  מתוזמנת)   │
                                                    └────────────┘
```

- **בזמן הנסיעה** הכול רץ על הטלפון: הקראת הסברים, שאלות אמריקאיות שעונים עליהן בקול ("תשובה 2"), וזיהוי דיבור. לא צריך אינטרנט.
- **שאלות חיות:** תקציב קטן ביום של שאלות חופשיות ל-Gemini. כשהתקציב נגמר או שאין קליטה, השאלה נשמרת לריצה הלילית.
- **מיד אחרי נסיעה:** האפליקציה מעלה לוג ל-`progress/`, ו-Gemini מכין שאלות חדשות על הטעויות ובודק את ההסברים שאמרת בקול.
- **בלילה (א'–ה'):** Claude מנתח דפוסים, כותב מחדש הסברים לטעויות שחוזרות, ומרחיב את הקורס. אם לא היו נסיעות חדשות, הריצה נעצרת מיד.

## אין עלות נוספת

- Gemini: מפתח API חינמי מ-AI Studio **בלי אמצעי תשלום מחובר**. כשהמכסה נגמרת הוא פשוט מפסיק לענות.
- Claude: משימה מתוזמנת שרצה על המנוי. Extra usage כבוי, כך שבמקרה הגרוע ריצה נכשלת.
- הקראה: מנוע הדיבור המובנה של אנדרואיד.

## מבנה ה-repo

| תיקייה | מה יש בה |
|---|---|
| `content/schema.md` | פורמט התוכן (קורס, יחידות, שאלות, טעויות חשיבה) |
| `content/courses/nodejs-backend/course.json` | מפת המושגים של הקורס |
| `content/courses/nodejs-backend/curriculum.md` | אותה מפה, בגרסה קריאה |
| `content/courses/nodejs-backend/units/` | יחידות הלימוד המלאות |
| `progress/` | לוגים מהאפליקציה (אחרי כל נסיעה) |
| `tools/` | סקריפטים לבדיקת התוכן ולהפקת הגרסה הקריאה |
| `android/` | אפליקציית האנדרואיד (Kotlin) |
| `.github/workflows/` | בנייה אוטומטית של קובץ ההתקנה |

## בדיקת תוכן

```bash
python3 tools/validate.py          # בודק את כל היחידות מול הסכמה ומפת המושגים
python3 tools/render_curriculum.py # מפיק את curriculum.md מתוך course.json
```

## התקנת האפליקציה

1. בכל שינוי, GitHub בונה את האפליקציה ומפרסם אותה ב-Releases בשם `latest`.
2. בטלפון: נכנסים לדף ה-Releases של ה-repo, מורידים את `drive-learning.apk` ופותחים אותו. בפעם הראשונה צריך לאשר התקנה ממקור לא ידוע.
3. כדי שהאפליקציה תופיע ב-Android Auto: בהגדרות Android Auto לוחצים 10 פעמים על Version and permission info, ואז בתפריט שלוש הנקודות נכנסים ל-Developer settings ומסמנים Unknown sources.
4. גרסה חדשה מותקנת מעל הקודמת, וההתקדמות נשמרת.

אפשר להשתמש גם בלי Android Auto: מפעילים מהטלפון, והקול עובר לרכב ב-Bluetooth.
